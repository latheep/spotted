# spotted
Spotted Clothing eBay Template

## eBay HTML Description Maker

A professional, easy-to-use tool for creating beautiful HTML descriptions for eBay listings. Perfect for clothing retailers and sellers who want to create attractive, branded product listings.

### Features

- **Live Preview**: See your eBay listing as you type
- **Customizable Colors**: Personalize your listing with custom colors for headers, sections, and borders
- **Professional Design**: Clean, modern templates that look great on all devices
- **Copy to Clipboard**: One-click copy of the generated HTML code
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **No Installation Required**: Just open index.html in your browser

### How to Use

1. Open `index.html` in your web browser
2. Fill in the product information form:
   - Product Title (required)
   - Description (required)
   - Image URL (optional)
   - Features (one per line)
   - Condition, Size, Material
   - Shipping Information
   - Return Policy
3. Customize the colors if desired
4. Click "Generate Preview" to see your listing
5. Click "Copy HTML Code" to copy the HTML to your clipboard
6. Paste the HTML into your eBay listing description

### Deployment

To host this tool on GitHub Pages or any web server:

1. Simply upload the `index.html` file to your web hosting
2. Access it via your hosting URL
3. No server-side processing required - it's a pure client-side application

### Browser Compatibility

- Modern browsers: Chrome, Firefox, Safari, Edge (latest versions)
- Clipboard functionality works in all browsers with fallback for older versions
- Fully responsive design for mobile and tablet devices

### Security

- All user input is properly escaped to prevent XSS attacks
- No data is sent to external servers - everything runs locally in your browser

### Development

This is a standalone HTML file with embedded CSS and JavaScript. No build process or dependencies required.

To make modifications:
1. Edit `index.html` directly
2. Refresh your browser to see changes
3. All styling and functionality is self-contained
